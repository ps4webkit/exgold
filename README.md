# MCFORT9669 · Exclusive Edition

Персональный статический хост PS4 с прежней компоновкой главного экрана.

Поддерживаются **только** PS4 FW **13.02, 13.04, 13.50, 13.52**. Версия определяется по User-Agent; остальные прошивки не запускаются. Используется GoldHEN **2.4b18.13**, бинарный файл `goldhen.bin`. Это персональная сборка хоста, а не особая версия GoldHEN. Движок и бинарный payload не модифицировались.

## Что включено

- Один движок для четырёх прошивок, один GoldHEN, патчи под указанные версии.
- Тёмно-синяя палитра, прямоугольная золотая рамка, RU / EN / KZ, переключатель видимости кнопки журнала, синий заполнитель прогресса.
- Кэш AppCache охватывает только файлы, нужные этому маршруту. Интерфейс адаптирован под соотношение 16:9 и компактную высоту браузера PS4. Для демонстрации на ПК добавьте `?demo=1`.
- Журнал движка сохраняет технические строки на исходном языке для точной диагностики; подписи, настройки, подсказки и статусы интерфейса переключаются по языку.

## Отдельный сайт на GitHub Pages

1. Создайте **новый** репозиторий, например `mcfort-exclusive`.
2. Загрузите **содержимое папки HOST**, а не саму папку, в корень репозитория. Скрытый файл `.nojekyll` тоже включите. Файлы `index.html`, `host.appcache` и `goldhen.bin` должны находиться в корне.
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку `main` и каталог `/(root)`.
4. Откройте `https://<ваше-имя>.github.io/mcfort-exclusive/` на PS4 с интернетом, дождитесь «Файлы готовы», полностью закройте браузер и откройте адрес снова. Только после этого проверьте офлайн.

Новый репозиторий имеет собственный адрес и не заменяет существующий `/9669/`. Кэш хранится браузером для конкретного адреса; при переходе на новый адрес его нужно сохранить заново. GitHub Pages публикует страницу открыто. Отображаемая надпись «персональный» не ограничивает доступ другим людям.
