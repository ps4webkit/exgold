Настройки оформления

Оформление и настройки относятся к стартовому экрану. Журнал включается штатным параметром загрузчика; для обычного запуска оставьте его выключенным.

Как пользоваться

Откройте адрес на PS4 с прошивкой 13.02. При первой установке дождитесь загрузки офлайн-файлов, затем нажмите «ВЗЛОМ». На последующих запусках сохранённый кэш позволит открыть хост без сети. После ошибки перезагрузите консоль перед новой попыткой. Не закрывайте страницу во время работы загрузчика.

О комплекте

Exclusive Edition для PS4 13.02. Цепочка запуска и патч взяты из aiofix. Для FW 13.02 выбран GoldHEN 2.4b18.13 из нового архива; работа этой комбинации на консоли пока не подтверждена. Число успешных запусков определяется по результату на самой консоли.
