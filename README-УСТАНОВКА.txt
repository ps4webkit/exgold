PS4 WEBKIT · EXCLUSIVE EDITION · FW 13.02 · GoldHEN v2.4b18.13

Это отдельный экспериментальный вариант прежнего ZIP. На 13.02 исходный aiofix использовал payload2.bin (его файл совпадал с лежащим рядом старым goldhen.bin). Здесь только для 13.02 выбор payload изменён на новый goldhen.bin из присланного архива GoldHEN v2.4b18.13. Старый payload2.bin сохранён в комплекте. Этапы WebKit, системного взлома и патч 1302.bin не менялись.

Установка: загрузите все файлы и папку patches в корень отдельного репозитория GitHub Pages. Откройте опубликованный адрес на PS4 13.02, дождитесь завершения кэша, нажмите «ВЗЛОМ». После ошибки перезагрузите PS4 перед повтором. Для возврата к проверенному вами исходному варианту используйте предыдущий архив целиком, не смешивая файлы и кэш двух версий.

Бинарный GoldHEN заявляет поддержку 13.02, его формат принят загрузчиком (первый байт E9), размер читается динамически. Это статическая проверка; фактический запуск комбинации на PS4 не проверен и 100% успешность не гарантируется. Счётчик на стартовом экране считает переходы к загрузчику, а не подтверждённые успешные взломы.

Хостинг должен отдавать cache.appcache с MIME text/cache-manifest. После обновления желательно закрыть браузер и повторно открыть хост, чтобы активировалась новая версия кэша.
